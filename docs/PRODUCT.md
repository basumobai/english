# 产品行为与当前范围

当前只做 Web 英语 AI 助学。内置北师大版2019七册2,137个教材出现位置，含167个短语/搭配及236个星号位置；按册次、Unit、课节、星号、单词/短语浏览和学习。仍支持管理员四字段自建词库，教材未列的音标/词性不凭空补写。Android 客户端不是本轮开发范围。

## 账户与内容

管理员创建账户、指定角色与模型权限组。新用户先修改初始密码，之后有独立学习记录。每个组可授权聊天和语音模型，不设置调用次数或对话数量额度。教材词库是共享内容，个人复习/暂停状态独立。

词库导入支持 UTF-8 CSV、TSV、空格格式（音标使用 /.../ 或 [...]）。先预览全部错误，存在错误时不部分写入；确认后事务批量写入。重复词义跳过，同词不同词性/释义保留；默认保留已有音标，勾选后可更新。四字段自建导入不强制 Unit/册次。短语的音标和词性可空（CSV/TSV保留空列）；单词仍要求完整四字段。导入操作可幂等重放。

## 复习

recognition、meaning_recall、spelling、listening_spelling 独立记忆。按计划取到期能力优先，新能力随机；同词义一轮只出一种题型，当天其他题型避让。学习日按个人 IANA 时区划分，默认 Asia/Shanghai。同题型的到期学习步仍可当天再练。

每日预算按首次引入的不同词义累计，跨轮次生效；本轮 new_limit 再受剩余每日预算约束。设为 0 仅复习，到期复习不受新词预算影响。撤销首次引入会恢复预算。自由练习可提前随机抽题，仅记录答题/评价，不改变正式 FSRS 状态。暂停的词义不加入新轮次，已有练习保持原次序。

答后停留核对，展示参考答案、音标、词性、例句。未命中释义别名的答案明确由学生自评，不冒充 AI 判分。错答或提示后只能选重学。FSRS-6 保存完整记忆状态，使用官方 go-fsrs/v4 v4.0.0；目标记忆率 80%–97% 可设置，默认 90%。改变记忆率作用于后续评价，不立即批量改写既有到期时间；未做个人权重拟合。

一个账户只有一个活动词汇练习，其他账户可并行学习。服务端恢复题目、反馈及进度，答题/评价/撤销有幂等编号，撤销原子恢复快照。浏览器待提交记录按账户分开，切换账户不能重放另一人的请求。当前不提供离线启动、离线题库或同步引擎。

词库显示未独立记住次数，累计达 8 次提示先理解语境，可自行暂停/恢复；不自动把词条删除或隐藏。统计按个人学习日显示完成、独立记住、重学和提示，包含自由练习，不声称为真实长期保持率。

## AI 与听力

辅导对话、句子拆解和听力训练有独立入口与可恢复历史。模型选择只能来自权限组，服务端再次检查授权。句子输出包含主干、语法片段、译文、改写和理解检查。听力按主题与 A2/B1/B2 生成原创内容；先做题，后显示原文与定位依据，不能提交后改答案获取高分。

现代 TTS 由配置的兼容模型生成，提供音色试听、播放速度和重复播放缓存。无设备机械 TTS 自动回退。缺少模型授权或 API Key 时明确提示配置，不假装调用成功。AI 内容与语音有生成标识。

## 尚待完善

大型词库队列索引与候选抽样（当前 3000 个候选）、自动备份与恢复演练、个人 JSON 导入恢复、完整账户删除/留存政策、个人 FSRS 参数拟合、错因诊断、长期趋势与复习负荷预测，以及 AI 训练内容的质量抽检。正式上线前仍需部署环境与安全评审。

## 本轮交互改进

快速四选一保留原普通6秒/困难和绝望3秒的默认值，增加2/3/6秒独立计时，教材和短语范围真正参与服务端选题。只有已审核选项可用；无符合内容时解释原因。答错或超时停留，答对自动下一题可关闭，服务端不因停止、刷新或网络重试延长截止。练习优先回访近期错项，并避免有其他选项集时紧接着重复同题。

词库和快选反馈中的AI讲解只在主动请求时调用授权模型，解释用法、搭配与易混点，给原创例句和新的练习。讲解保存在本人对话，AI文本不自动写回教材、正式判分或FSRS。

独立拆句允许先标主语/谓语/从句/修饰等范围、写译文，明确跳过后也可直接请求参考。AI分析会对照学生的尝试；原文引用和Unicode范围必须有效。查看参考后只通过新句继续独立验证，不把背过的原句当新证据。原题到拆句入口限本人已交卷英语原文，记录可恢复。听力交卷后保存“没听懂/听懂但忘了”的反思和训练方向。

广东听说录音可主动保存到本人账户，授权ASR模型通过OpenAI兼容Audio Transcriptions接口转写。文本需自己核对，仍支持手填；不提供专业发音评分。
